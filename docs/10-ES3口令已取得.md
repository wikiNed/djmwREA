## 二、静态取证链（从 `SaveManager..ctor` 一路到字面量）

### 2.1 先修正 `docs/07` 的一个错误

`docs/07` 第三节把 GOT 槽 `0x35e7408` 的 RELA addend 记成 `0x36F5DB0`，**是错的**。
用 `scripts/rela_resolve.py` 复算：

```
r_offset = 0x35e7408   type = 1027 (R_AARCH64_RELATIVE)   addend = 0x36FC618
```

交叉验证（相邻 GOT 项，均 type=1027）：

```
0x35e7400 -> 0x36bd4a0
0x35e7408 -> 0x36fc618   ★
0x35e7410 -> 0x36e5890
```

`0x36F5DB0` 落在 `.data` 里一段无关数据上，当初"一串递增 8 的指针、不是
`Il2CppString*`"的结论，是追错地址的产物。

### 2.2 `SaveManager..ctor` @ RVA `0x17A64D8`

```asm

0x17A64DC: stp  x22, x21, [sp, #0x10]
0x17A64E0: stp  x20, x19, [sp, #0x20]
0x17A64E4: adrp x21, #0x385e000
0x17A64E8: adrp x22, #0x35e3000
0x17A64EC: adrp x20, #0x35e7000
0x17A64F0: ldrb w8, [x21, #0x28a]        ; cctor 已执行标记
0x17A64F4: ldr  x22, [x22, #0x270]
```

`0x35e7408` 是标准 il2cpp **metadata-usage GOT 槽**：
加载时 `*(0x35e7408) = base + 0x36FC618`，首次访问时 `il2cpp` 把该地址中的
哨兵替换成真正的 `Il2CppString*`，`ldr x2, [x20]` 拿到的就是这个字符串。

### 2.3 哨兵 → 字面量下标

`0x36FC618`（文件偏移 `0x36f0618`）处内容：

```
f3 5e 00 a0 00 00 00 00 | f5 5e 00 a0 00 00 00 00 | f7 5e 00 a0 00 00 00 00 | ...
```

编码规则：

```
哨兵值 = 0xA0000000 | ((index << 1) | 1)
0xA0005EF3 -> index = 0x5EF3 >> 1 = 0x2F79 = 12153
```

### 2.4 字面量表 `global-metadata.dat`

metadata header 的第 0 对 `(offset,size)` 描述 `stringLiteral` 表：

```
表头   off=0x100      size=0x207b8 (133048)  -> 16631 行，每行 8 字节
数据   off=0x208b8    size=0x7a26c (500332)  -> stringLiteralData
```

**行格式是 length-first：`(int32 length, int32 offset)`。**
（踩过的坑：写成 offset-first 会读出长度 39 万字节的垃圾。）

第 12153 行：

```
len = 12   offset = 0x5f71d   ->  'hqgames@2013'
```

邻行 sanity check（字母序字典，完全自洽）：

```
12152  'hover'
12153  'hqgames@2013'   ★
12154  'hr'
12155  'hr-BA'
```

## 四、解密后存档的形态（新发现）

明文**不是**以 `{` 开头：

```
o74JUkh9jw==" : {
        "__type" : "string",
        "value" : "6B01C5B95CCF00CE..."
```

`saves/SaveFile.es3` 更残，开头是 `_Key" : {...`。

即 ES3 写文件时把最外层的 `{` 丢掉了，这不是解密失败。解析需要补一个引号：

```python
s = plaintext.decode('utf-8').lstrip()
obj = json.loads('{"' + s if not s.startswith('{') else s)
# 9 个 key: o74JUkh9jw== / ChongWu01ShuChu_Key / Hero06ShuChu_Key / ...
```

另外 `SaveFile.es3` 与 `SaveFile_orig.es3` 的内容**不是** 14 段 `$` 拼接的正式存档，
而是一层 key-value 桶；真正的 14 段存档是 `saves/playerDate_01/02/03.json`
（41246 / 42583 / 104886 B，明文 JSON，不需要解密）。

## 五、对路线 A（真机动态 dump）的意义

原计划在真机上 hook `ES3Settings..ctor` 抓 `x2`。**现在不需要了** ——
口令已经从纯静态链推出来了，`docs/07` 里所有 frida/tombstone 的折腾可以归档。

仍然保留价值的部分：

- `il2cpp_runtime_class_init` 常驻地址 `0x1653b4c`
- `il2cpp` 对象分配 `0x1653d94` / 写屏障 `0x1653af8`
- `.dynsym` 在 il2cpp 段内**只有 1 个符号**，所以任何靠导出符号定位的思路都不可行
