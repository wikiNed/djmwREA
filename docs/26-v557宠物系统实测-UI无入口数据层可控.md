### 2.3 但 `GameGUI.ChongWuUIGO` 是**战斗内**字段

## 六、结论

1. **goal ① 的原始表述「宠物 UI 视觉验收」在 v5.5.7 上不可完成**——
   不是因为改档失败，而是因为这版**没有可点到的宠物界面**。
   prefab 在包里、脚本在 metadata 里，但场景 UI 无入口。
2. **宠物系统的真实通路是「数据层 + 战斗内加成」**：
   改 `IsXieDai` 立即影响战斗力，且状态被游戏持久化。
3. 因此把验收标准调整为**可交付的形式**：
   - 宠物数据结构（8 字段）✅
   - 改档 → 战斗力变化（1 → 3.60万，走麒麟臂）✅
   - 游戏回写保留宠物状态 ✅
   - 宠物 UI 截图 ❌（无入口，附资源层证据说明原因）
4. 如果一定要看宠物 UI，只有两条路：
   - 用 frida/hook `GameGUI.OpenChongWuUI`（`tok=0x060005a9`）强行调用
   - 换 v5.9.2（TapTap 版）——但那版有登录墙

## 九、踩坑（本轮新增）

1. **Unity 输入框：验证码填完不能按 BACK**（会清空该框）。
   填完直接点按钮，第一次可能被键盘吃掉，**再点一次**即可。
2. **`sed -i` 替换串里的 `&` 代表整个匹配**，会把 prefs 文件写坏。
   改 prefs 一律用 Python 重写整个 XML（`E:\DSH\game\fix_accprefs.py`）。
3. **战斗胜利后不会自动退出**，要进「设置」页点「返回世界地图」。
4. **新手指南弹窗会盖住主界面**，点屏幕空白 `(360,250)` 可关闭。
5. **`Il2CppFieldDefinition` 步长是 12 字节**（nameIndex / typeIndex / token），
   不是 16。用前 4 条能否读出合法字段名判别。
